# Study Task Manager

一个用 Python 编写的命令行学习任务管理器。程序需要 Python 3.8 或更高版本，只使用标准库。

## 运行方式

在 PowerShell 中运行：

```powershell
cd D:\Projects\study-task-manager
python task_manager.py
```

## 菜单操作

| 输入 | 操作 |
| --- | --- |
| `1` | 添加学习任务。输入标题并回车。 |
| `2` | 查看所有任务及其完成状态。 |
| `3` | 从列表中选择编号，将任务标记为已完成。 |
| `4` | 从列表中选择编号，删除对应任务。 |
| `0` | 退出程序。 |

任务编号从 `1` 开始。删除任务后，列表会重新编号，下次操作以当前显示的编号为准。

## 数据保存

程序首次启动时，会在 `task_manager.py` 同目录下创建 `tasks.json`。添加、标记完成或删除任务后，程序会立即保存。再次启动时会读取上次的任务。

如果 `tasks.json` 内容损坏或结构无效，程序会提示错误并退出，原文件会保留。恢复有效的文件后即可重新运行。

`tasks.json` 是本地数据文件，已由 `.gitignore` 排除。
